# lalallala

Project-scoped MCP servers are defined in `.mcp.json`:

- **context7** – up-to-date library docs.
- **firecrawl** – web scraping. Get a free API key at firecrawl.dev and export it
  before launching Claude Code: `export FIRECRAWL_API_KEY=...` (never commit the key).
- **playwright** – browser automation (requires Node.js).
